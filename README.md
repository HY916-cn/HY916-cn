## 关于我

我是 Haoyu，常驻新加坡。我主要开发可自托管的 Web 系统、macOS 原生工具与服务器基础设施。

我偏爱边界清晰、默认可用、真正能够部署和长期维护的软件。比起堆叠功能，更在意一个工具能否把具体问题解决完整。
